# HIITUN Media website

This directory contains the static site for https://media.hiitun.top.

Vercel project: `hiitun-media`  
Production branch: `media-site`  
Root directory: `media-site`

Push reviewed changes to the `media-site` branch to trigger a production deployment. The `main` branch belongs to a separate website. Download links are managed in `index.html`; proxy routes and response headers are configured in `vercel.json`.

三个计划的主要区别是什么？

体验版支持 3 个平台账号和 1 个配置。标准版和专业版均支持 50 个平台账号和 8 个配置。

使用 AI 如何计费？

内置 AI 每次成功生成或改写扣 1 积分。使用自有 API 时，费用由你向所选提供商支付。

草稿和素材会上传到 HIITUN 云端吗？

草稿和素材保存在本机，操作时才连接平台或 AI。账号与订阅信息按隐私政策处理。

如何登录？

点击“登录”，使用桌面软件注册的 HIITUN 账号邮箱和密码登录。
